What it does

Obsidian stores everything as plain markdown on disk. Notion stores everything as blocks in a proprietary API. This tool bridges the gap without you having to click-import 500 notes one at a time.

📁

Preserves folder structure

Every folder becomes a nested Notion page, exactly where you'd expect it.

🔗

Resolves wiki-links

[[Note Name]] becomes a real Notion page mention, not broken text.

🖼️

Uploads attachments

Images and files are uploaded to Notion via the file API — no manual dragging.

♻️

Resumable

Saves progress to a state file. Ctrl-C whenever — re-run to pick up where you left off.

🔍

Dry-run mode

Preview everything that would happen before making a single API call.

🏷️

Frontmatter tags

YAML frontmatter is preserved as a callout block with your tags intact.

What's handled (and what isn't)

Supported

  • Headings (H1–H6)
  • Bold, italic, strikethrough, code
  • Bullet and numbered lists
  • Checkboxes / task lists
  • Code blocks with language
  • Blockquotes
  • Callouts (> [!NOTE], etc.)
  • [[Wiki-links]]
  • ![[Embedded images]]
  • External image URLs
  • YAML frontmatter tags
  • Obsidian ==highlights==

Not supported

  • Canvas files (.canvas)
  • Dataview queries
  • Markdown tables
  • Nested list indentation
  • Templater / plugin syntax
  • Files larger than 20 MB

How to use it

1

Create a Notion integration

Go to notion.so/my-integrations, click New integration, and copy your token (secret_...). Then open the Notion page you want to migrate into, click ··· → Connect to, and pick your integration. Copy the page ID from the URL — it's the 32-character hex string after the last /.

2

Download and run the installer

Click Download migrate.sh above — or copy the curl command from the terminal at the top of this page. Run it, and the wizard handles everything from here: installs the tool, auto-detects your vaults, walks you through Notion setup, and runs the migration.

3

Done

The installer runs a dry-run preview, asks you to confirm, then migrates everything. Progress is saved as it runs — if it's interrupted, re-run ./migrate.sh and it picks up where it left off.

Your vault is in Notion. Cross-note links are resolved, attachments are uploaded, and the folder hierarchy is intact.

All options

--vault PATH            Path to your Obsidian vault directory (required)
--token TOKEN           Notion integration token, starts with secret_ (required)
--root-page PAGE_ID     Notion page ID to migrate content into (required)
--dry-run               Preview without making any API calls
--skip-attachments      Skip uploads; note filenames as text instead
--reset                 Delete state file and restart from scratch
--state-file PATH       Custom path for the resume state file
